# Inkstone for Orca

Six Chinese-colour themes — three light, three dark — that paint Orca's
interface and its terminal from one semantic palette. Version 0.5.0.

Part of [Inkstone](https://github.com/wahaha1024/inkstone), where the same six
palettes generate VS Code, Ghostty, Kaku, OpenCode, Zed and DeepSeek Harness
themes. Generated by `pnpm build` — do not edit by hand.

## Themes

| Theme | Slot | Palette |
| --- | --- | --- |
| Inkstone Xuanmo | dark | Pine-soot ink underfoot, cinnabar for annotations. The dark canvas gives the brightness back to your code, and red is kept for what needs to be seen — built for long nights. |
| Inkstone Xuanmo Dimmed | dark | The same ink with the lights turned down. A deeper canvas, ink that never turns gray, and pigments that give up half a step of saturation — for softer rooms. |
| Inkstone Xuanzhi | light | Raw xuan paper, pine-soot ink, mineral washes. Warm paper, cool ink, and mineral colors in between; keywords use a softened cinnabar that reads as a brush annotation, not an alarm. |
| Inkstone Xuanzhi Dimmed | light | Aged paper in warm gray, with ink a shade deeper. Like an old book page in afternoon light: the paper stops glaring, the pigments fade half a step, but every hue is still recognizable. |
| Inkstone Canghai | dark | Deep-sea twilight, blue-green minerals, a single touch of vermilion. A cool canvas that stays quiet without going flat. |
| Inkstone Qingci | light | Moon-white glaze, blue-gray ink, sky-after-rain. Like a Ru ware bowl: the color sits under the glaze and never competes with the text — for daylight and light desks. |

Each theme ships an app theme (interface colours and code highlighting) and a
terminal palette with the same name, so a terminal beside an editor shows one
colour.

## Install

From the Orca plugin store: **Settings → Plugins**, search for "Inkstone", then
pick a theme under **Settings → Appearance**:

- **Light theme** — Inkstone Xuanzhi, Inkstone Xuanzhi Dimmed, Inkstone Qingci
- **Dark theme** — Inkstone Xuanmo, Inkstone Xuanmo Dimmed, Inkstone Canghai

The terminal palette is chosen separately, under **Settings → Terminal**.
